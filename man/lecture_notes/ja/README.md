# 有限次元フォン・ノイマン環：講義ノート

本講義では、有限次元フォン・ノイマン環、すなわち環
$\bigoplus_cM_{k_c}(\mathbb C)$ の理論を、量子物理学、量子情報、ランダム行列理論および機械学習への応用とともに解説する。

本講義は二種類の読者を同時に想定して書かれている。

- **数学者**には、自己完結したテキストを与える。述べられるすべての定理、公式、定数、不等式は、下に挙げる予備知識から出発して本講義の中で証明される。証明の場所はその章自身か、番号を付けて引用する付録 A–F のいずれかである。計算されるだけの数値（たとえば大きな $n$ での準位統計）は *数値的観察* と明示し、前提やテストの目標としては決して用いない。文献は歴史的な帰属や発展的な読み物のために挙げるものであり、証明の代わりになることは決してない。
- **物理学者と技術者**には、*物理的意味* と題した囲みで各概念の物理的意味を与える。これらの囲みは物理的解釈であり、本講義の定理ではない。他の箇所で証明される事柄は何一つこれらに依存しない。
  自分の用途に合わせて改変できる動作するコードは[チュートリアル](../../tutorial/ja/README.md)にある。

第 1–13 章は同じ構成をとる。すなわち、完全な証明付きの定義と結果、計算例、そして解答付きの演習問題である。ライブラリ `torch_vn_algebra` が計算または検証する各結果の後には、*計算：* または *ライブラリでは：* の行があり、それを行っている[チュートリアル](../../tutorial/ja/README.md)の箇所へリンクしている。

## 予備知識

本講義は以下のことだけを仮定し、それ以外のすべてを証明する。

- $\mathbb R$ および $\mathbb C$ 上の（有限次元の）線形代数と、代数学の基本定理。
- 標準的な実解析と多変数の微分積分：極限、連続性、$\mathbb R^n$ におけるコンパクト性、微分、平均値の定理、テイラーの公式、逆関数定理と陰関数定理。
- 標準的な測度論と積分論：ルベーグ測度、直積測度とフビニ–トネリの定理、優収束定理と単調収束定理、$\mathbb R^n$ における変数変換、押し出し測度、密度、独立性。
- 初等的な確率論：期待値、分散、独立性、ガウス分布とその積率母関数、マルコフの不等式とチェビシェフの不等式、大数の法則。

物理学と関数解析の知識は仮定しない。
