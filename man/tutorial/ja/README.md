# チュートリアル：講義ノートに沿った torch_vn_algebra

このチュートリアルは、[講義ノート](../../lecture_notes/ja/README.md)の文脈で、PyTorch ライブラリ `torch_vn_algebra` を用いて（CPU と GPU 上で）有限次元フォン・ノイマン環 $`\bigoplus_cM_{k_c}(\mathbb C)`$、すなわち対称性セクターをもつブロック対角行列をどのように計算するかを示す。扱うのは、ランダム行列とハール分布のユニタリ行列、量子状態・量子チャネル・エントロピー、シュレーディンガー方程式とリンドブラッド方程式による時間発展、対称性セクターにおけるスピン鎖と厳密対角化、群表現のウェダーバーン分解、量子誤り訂正、同変層、ジョルダン代数である。各チュートリアルは、同じ番号の講義ノートの章に対応する：そこで証明された結果に対するライブラリのコードを示し、厳密な結果（定理、閉じた公式、あるいは独立な計算）によってコードを検証し、節 *比較の対象* で同じ作業のための標準的な道具を挙げる。各節は、その節と用いる結果へリンクする *講義ノート：* の行で始まる。計算されるだけの数値（たとえば大きな $`n`$ での準位統計）は *数値的観察* と明示し、前提やテストの目標としては決して用いない。講義ノートの[予備知識](../../lecture_notes/ja/README.md#prerequisites)に加えて、チュートリアルは Python を仮定する。

チュートリアルのすべてのコードはテストスイート（`tests/test_man.py`）によって実行されるので、どの例もライブラリの現行版で動作する。

## コードの実行方法

```bash
pip install -e .                # from the root of the repository
python -m pytest tests/test_man.py -q
```

各章のコードブロックは、順番どおりに一つの Python セッションまたは Jupyter ノートブックに貼り付けて実行できる。同じ章のブロックは変数を共有する。
