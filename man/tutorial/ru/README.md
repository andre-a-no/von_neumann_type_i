# Руководство: torch_vn_algebra в контексте конспекта лекций

Это руководство показывает, как проводить вычисления с конечномерными алгебрами фон Неймана $`\bigoplus_cM_{k_c}(\mathbb C)`$,
то есть с блочно-диагональными матрицами с секторами симметрии, в библиотеке `torch_vn_algebra` для PyTorch (на CPU и
GPU) в контексте [конспекта лекций](../../lecture_notes/ru/README.md): случайные матрицы и унитарные матрицы Хаара,
квантовые состояния, каналы и энтропии, динамика Шрёдингера и Линдблада, спиновые цепочки и точная диагонализация в
секторах симметрии, разложения Веддербёрна представлений групп, квантовая коррекция ошибок, эквивариантные слои и
йордановы алгебры. Каждое руководство сопровождает главу
конспекта лекций с тем же номером: в нём приводится код библиотеки для доказанных там результатов, код проверяется по
точному результату (теореме, явной формуле или независимому вычислению), а в разделе *С чем сравнивать* названы
стандартные инструменты для той же задачи. Каждый раздел начинается строкой *Конспект:*, ведущей к соответствующему
разделу конспекта и используемым результатам. Числа, которые только вычисляются (например, статистика уровней при
больших $`n`$), помечены как *численное наблюдение* и никогда не используются ни как посылки, ни как цели тестов. Помимо
[предварительных сведений](../../lecture_notes/ru/README.md#prerequisites) конспекта лекций, руководство предполагает знание Python.

Весь код руководства выполняется набором тестов (`tests/test_man.py`), поэтому каждый
пример работает с текущей версией библиотеки.

## Как запускать код

```bash
pip install -e .                # from the root of the repository
python -m pytest tests/test_man.py -q
```

Все блоки кода главы можно по порядку вставить в один сеанс Python или в блокнот
Jupyter. Блоки одной главы используют общие переменные.
