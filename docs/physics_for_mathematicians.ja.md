# 数学者のための物理：`torch_vn_algebra` のための用語対照

*本文書は英語版の翻訳である。両者の内容が食い違う場合は英語版が優先する。*

本ガイドは、作用素環論を専門とする読者が、本ライブラリおよび論文に現れる物理モデルの意味を理解するためのものである。
すべては H = ⊕_c C^{k_c} に作用する環 M = ⊕_c M_{k_c}(C) の言葉で述べる。各物理概念について、それが M の中で何に当たるか、
そしてライブラリのどこにあるかを示す。

---

## 0. 基本的な考え方

物理的な対称性とは、群 G の H 上のユニタリ表現 π のことである。対称性と両立するもの（ハミルトニアン、時間発展、
超選択則の下での観測量）はすべて**可換子環（commutant）** π(G)' に属する。二重可換子定理とシューアの補題により

    H ≅ ⊕_λ V_λ ⊗ C^{m_λ},     π(G)' ≅ ⊕_λ M_{m_λ}(C),

が成り立つので、π(G)' は有限次元の I 型フォン・ノイマン環である。そのセクターは既約表現 λ、ブロックのサイズは重複度 m_λ であり、
中心は「チャージ」の関数からなる。したがって、対称性をもつ系をモデル化する物理学者は、そう呼ぶことはないにせよ、
実際には (1) の形の環の中で計算していることになる。保存量 Q（自己共役作用素）が一つだけの場合、セクターは Q の固有値、
ブロックはその固有空間である。

これは「なぜ一つの大きな行列を使わないのか」という問いへの答えにもなる。埋め込み M ⊂ M_N（N = Σk_c）は正確であるが、
次のものが失われる。
- **計算コスト**：N³ ではなく Σk_c³ で済む。C 個の等しいブロックの場合、時間にして C² 倍の差となる。
- **測度**：M のユニタリ群は Π U(k_c) であり、U(N) の中では零集合である。U(N) のハール測度に従うランダムなユニタリは
  M に属さず、M_N での勾配ステップは M の外に出てしまう。
- **トレース**：M_N 上のトレースは定数倍を除いて一意であるが、M 上の忠実なトレースは C 個のパラメータをもつ族 Σ w_c Tr_c をなす。
  「トレースを保存する」という性質や双対写像は重みに依存する。
- **中心**：セクター射影は系の古典的な部分である（第 2 節）。条件付き確率やポストセレクションは中心を用いた操作であり、
  一つの行列で扱う場合にはブロックの添字から再構成しなければならない。

C = 1 の場合もサポートしている。これは M_n におけるバッチ化された線形代数である。

## 1. 状態、観測量、測定

| 物理 | 数学 | ライブラリ |
|---|---|---|
| 観測量（エネルギー、スピン、粒子数） | 自己共役な A ∈ M | `Operator` |
| 測定で得られうる値 | A のスペクトル | `eigenvalues`, `eigh` |
| （混合）状態 | 正規正値汎関数 ω, ω(1) = 1；密度 ρ ≥ 0, Tr ρ = 1 | `DensityMatrix` |
| 純粋状態、「波動関数」 | ベクトル ψ ∈ H, ρ = \|ψ⟩⟨ψ\|（極小射影） | `vector_in_sector`, `basis_state` |
| 期待値 | ω(A) = Tr(ρA) | `expectation` |
| 測定値 λ が得られる確率 | ω(P_λ)、P_λ はスペクトル射影 | `apply_function` |
| 測定後の状態（Lüders 則） | ρ ↦ PρP / Tr(Pρ) | `lueders_update`, `condition_on` |
| フォン・ノイマン・エントロピー | S(ρ) = −Tr ρ log ρ | `entropy` |
| 温度、熱平衡状態 | ρ = e^{−βH}/Tr e^{−βH}（ギブス状態 = KMS 状態） | `gibbs_state` |
| 無限大温度 | トレース状態 τ / τ(1) | `tracial_state` |

**三つのトレースの物理的意味。**
- Tr_blunt（重み 1）は H 上の物理的なトレースである。正規化すると無限大温度の状態となり、N 個の基底状態がすべて等確率で、
  セクター c の確率は k_c/N である。
- Tr_norm（重み 1/k_c）：各セクター内でそれぞれ一様な（ミクロカノニカルな）状態。
- τ_vN（重み 1/(C k_c)）：各セクターのミクロカノニカル状態の一様な混合。（基底状態ごとではなく）*セクター*ごとの確率が 1/C となる。

任意の状態を中心に制限すると、セクター上の古典的な確率分布が得られる（`sector_probabilities`）。
物理学者が「チャージ q の確率」と呼ぶものはこれである。

## 2. 超選択則、デコヒーレンス、古典と量子

- **超選択則**（Wick–Wightman–Wigner）：異なるチャージ（電荷、フェルミオン・パリティ）をもつ状態の重ね合わせは観測できない。
  数学的には、許容される観測量はチャージの可換子環、すなわち B(H) 全体ではなく環 M をなす。
- **M の中心**は、擾乱を与えずに測定でき、すべてと可換な量、すなわち「古典的な」変数からなる。すべての k_c = 1 であれば
  系は純粋に古典的である（可換環、すなわち C 点上の確率空間）。C = 1 であれば純粋に量子的である。一般の場合はその混成である。
- **デコヒーレンス / einselection**（Zurek）：環境との相互作用により非対角ブロック ρ_{cd}, c ≠ d が抑制される。これは条件付き期待値
  E: B(H) → M, ρ ↦ Σ P_c ρ P_c であり、実効的な観測量の環は M に縮小する。本ライブラリでは作用素ははじめから M に属するので、
  この条件付き期待値を施した結果が計算の出発点となる。

## 3. 閉じた系のダイナミクス

| 物理 | 数学 | ライブラリ |
|---|---|---|
| ハミルトニアン | 自己共役な H ∈ M | — |
| シュレーディンガー方程式 i dψ/dt = Hψ | ψ(t) = e^{−itH}ψ(0) | `dynamics.schrodinger`, `propagator` |
| フォン・ノイマン方程式 dρ/dt = −i[H, ρ] | ρ(t) = U ρ U*, U = e^{−itH} | `von_neumann` |
| ハイゼンベルク描像 | A(t) = U* A U（M の自己同型） | `solve_operator_ode` |
| 保存量 | [H, Q] = 0 を満たす Q | セクター |

H ∈ M ならば e^{−itH} ∈ M であり、ダイナミクスがセクターの外に出ることはない。各セクターは独立に時間発展し、
指数関数はブロックごとに計算される。

## 4. 開放系とチャネル

- **量子チャネル**とは、完全正値かつトレースを保存する写像（シュレーディンガー描像）である。その共役（ハイゼンベルク描像）は
  完全正値かつ単位的である。クラウス表示：Φ(ρ) = Σ_i K_i ρ K_i*。ライブラリでは `Channel`。
- **セクター間チャネル**（`InterSectorChannel`）は、チャージを変化させる過程を記述する：粒子の損失、崩壊、電子のトンネル脱出など。
  そのクラウス演算子のブロックは K^{dc}: C^{k_c} → C^{m_d} である。トレース保存性と双対写像は入力側と出力側のトレースの重みに
  依存するため、因子 w_out/w_in が現れる。
- **リンドブラッド方程式**（GKSL）はチャネルの半群 e^{tL} を生成する：
  dρ/dt = −i[H, ρ] + Σ_j γ_j (L_j ρ L_j* − ½{L_j* L_j, ρ})。
  L_j は「ジャンプ演算子」であり、それぞれが環境の系への作用の仕方を一つずつ表す。
  - **T1**（エネルギー緩和、振幅減衰）：L = σ⁻ = |0⟩⟨1|。量子ビットが励起状態から基底状態へ崩壊する。励起の数が一つ減るので、
    これはセクター**間**のジャンプである。例：`site_amplitude_damping`, `lowering`。
  - **純粋な位相緩和**（時間 T_φ）：L = σ^z。これは対角的でセクターを変えず、位相を壊すのみである。
    これはセクター**内**のジャンプである。
  - T1 と T2（1/T2 = 1/(2T1) + 1/T_φ）は、あらゆる量子コンピュータについて示される標準的なコヒーレンス時間である。

## 5. スピン鎖

- **1 サイト上のスピン ½**：H_site = C²、基底 |↑⟩, |↓⟩（または |1⟩, |0⟩）。パウリ行列 σ^x, σ^y, σ^z；
  S^a = σ^a/2；S^± = S^x ± iS^y は上昇演算子および下降演算子である。
- **L 個のスピンからなる鎖**：H = (C²)^{⊗L}, dim = 2^L。この指数関数的増大こそ、物理学者が対称性を必要とする理由である。
- **XXZ ハミルトニアン**：H = Σ_⟨ij⟩ [J/2 (S_i⁺S_j⁻ + S_i⁻S_j⁺) + JΔ S_i^z S_j^z] + Σ_i h_i S_i^z。
  第 1 項は隣り合う ↑↓ を入れ替え（「粒子のホッピング」）、第 2 項はそれらの相互作用、第 3 項は外場である。Δ = 1 はハイゼンベルク模型
  （磁性体）であり、Δ = 0 は（ジョルダン–ウィグナー変換により）自由フェルミオンと等価で、厳密な検証を可能にする。
- **保存チャージ**：S^z_tot、あるいは N = ↑ の個数（ビット列のハミング重み）。H のすべての項がこれを保存するので、
  H ∈ ⊕_{N=0}^{L} M_{C(L,N)} となり、ブロックのサイズは二項係数で与えられる。
- **セクターの融合**（`fused_tensor_product`）：テンソル積の下でチャージは加法的である。これは U(1) の融合則
  (⊕_q M_{n_q}) ⊗ (⊕_r M_{m_r}) ⊂ ⊕_s M_{Σ_{q+r=s} n_q m_r} である。`SpinChain` はこの方法で、サイトごとに基底を構成する。
- **運動量**（`momentum_algebra`）：環状の鎖には並進対称性 T（群 Z_L）もある。e^{ik} を T の固有値とする同時固有空間 (N, k) により、
  ブロックがおよそ L 分の 1 に小さくなる、より細かい分解が得られる。
- **基底状態**とは H の最小固有値に対応する固有ベクトル、すなわち絶対零度での振る舞いである。大きなブロックでは
  ランチョス法（`krylov`）によって求める。
- 論文で検証している事項と、それらが標準的なテストである理由：
  - ハイゼンベルク環の基底エネルギー（厳密値が既知、ベーテ仮説）；
  - **マーシャルの符号則**：2 部格子上のハイゼンベルク模型では、基底状態の符号は (−1)^{一方の副格子上の ↑ の個数} となる。
    これは定理であり、そのため明快なテストとなる；
  - **SU(2) の入れ子構造**：ハイゼンベルク模型は完全な SU(2) 対称性をもつので、N < L/2 に対してセクター N のスペクトルは
    セクター N+1 のスペクトルに含まれる（多重項）；
  - **磁壁の融解**：Δ = 0 における |↑…↑↓…↓⟩ は既知のプロファイルで広がる；
  - **Peschel の公式**：相関行列から自由フェルミオンのエンタングルメント・エントロピーを与える。
- **乱れとカオス**（`random_field_heisenberg`, `level_spacing_ratio`）：ランダム場 h_i ∈ [−W, W]。W が小さいとき系は「カオス的」であり、
  準位は GOE と同様に反発し合う（⟨r⟩ ≈ 0.53）。W が大きいとき系は局在し（多体局在（MBL））、準位はポアソン過程のように
  独立となる（⟨r⟩ ≈ 0.386）。準位統計は**一つのセクターの内部で**のみ意味をもつ：セクターを混ぜると人為的にポアソン統計が生じる。
  これは、セクターをもつ環の中で計算することを支持するよい物理的根拠である。

## 6. エンタングルメントと部分系

- 複合系 A+B：H_A ⊗ H_B、環 M_A ⊗ M_B。
- **縮約状態** ρ_A = Tr_B ρ は、汎関数 ω を部分環 M_A ⊗ 1 に制限したものである。密度行列の言葉では条件付き期待値（部分トレース）である。
  ライブラリでは `partial_trace`, `reduced_state`。
- 純粋な ρ の**エンタングルメント・エントロピー** S(ρ_A) は、A と B の間の量子相関を測る。
- **Page の公式**：ランダムな純粋状態における部分系のエントロピーの厳密な平均値。サンプラーがハール分布に従うことのテストに用いる。
- **対称性分解エンタングルメント**：チャージが保存されるとき ρ_A はブロック対角であり、そのエントロピーは「古典的」部分
  （中心上の分布のエントロピー）と「量子的」部分（ブロックのエントロピーの平均）に分かれる。これは中心の直接的な応用である。

## 7. 量子計算

- **量子ビット** = C²、n 量子ビット = (C²)^{⊗n}；**ゲート**はユニタリ；**回路**はゲートの積；計算基底での**測定**は σ^z の
  スペクトル射影を用いる。
- **QAOA**（量子近似最適化アルゴリズム / 交互作用素仮説）：e^{−iγ H_C}（H_C は対角で目的関数を符号化する）と
  e^{−iβ H_M}（「ミキサー」）を交互に作用させる。「ちょうど k 個が 1」という制約をもつ問題（n 個から k 個を選ぶ）では
  **XY ミキサー** Σ(X_iX_j + Y_iY_j) = 2Σ(σ⁺σ⁻ + h.c.) を用いる。これはハミング重みを保存するので、回路全体が ⊕_N M_{C(n,N)} に属し、
  実行可能解はちょうどセクター N = k となる。
- **ノイズ**：T1 は実行可能なセクターから外れる（1 が一つ失われる）が、位相緩和は外れない。
- **ポストセレクション**：ハミング重みを測定し、誤った試行を捨てる。これは**中心的な**射影 P_k による Lüders 則
  ρ ↦ P_kρP_k / Tr(P_kρ) であり、成功確率は ω(P_k) である。`ex9_qaoa_xy_mixer.py` が行っているのはこれである。
  T1 ノイズのみの場合、すべての T1 ジャンプはセクターの外に出るので、ポストセレクションによって理想状態が厳密に復元される（F = 1）。
- デコヒーレンス・フリー部分空間と作用素環的誤り訂正：保護すべき情報は、ノイズが作用しない環の一つのブロック
  （あるいはブロックの一つのテンソル因子）に符号化される。これもまた I 型環の言葉である（Knill–Laflamme–Viola, Bény–Kempf–Kribs）。

## 8. ランダム行列、実と複素

これはパラメータ `complex_valued` に直接関係する。
- **反ユニタリ対称性**とは時間反転 T のことである。T² = 1（スピンをもたない粒子、磁場なし）ならば、適当な基底で H は**実**となる：
  GOE、直交アンサンブル、COE。実数演算で十分であり、メモリは半分で済み、計算も速い（論文の計算時間の表を参照）。
- そのような対称性がない場合（磁場、複素位相、運動量 k ≠ 0, π）H は複素となる：GUE, CUE。複素数が必要である。
- T² = −1（スピン軌道相互作用のある半整数スピン）の場合は四元数的である：GSE, CSE。
- 実の外場をもつ XXZ 模型は実である。k ∉ {0, π} の運動量セクターは複素である。ダイナミクス e^{−itH} は、H が実であっても常に複素である。
  これが論文の「どの場合に何で足りるか」の表である。
- 小さな差が問題となる場合には倍精度が必要である：縮退したスペクトル、1e−12 までの精度で検証する恒等式、長時間の時間発展、
  多くのステップを要するランチョス法など。多数のサンプルにわたる統計には単精度（およびテンソルコア上の TF32）で十分である。

## 9. 機械学習

同変な線形層とは、群の表現と可換な写像 W: V → V である（畳み込みでは並進、グラフニューラルネットワークでは置換、分子では回転）。
シューアの補題により、そのような W の空間は重複度 m_λ をもつ ⊕_λ M_{m_λ} であり、したがって同変層は (1) の形の環の元によって
パラメータ付けられる。本ライブラリは、そのようなパラメータ付けに対して、正しい測度によるランダム初期化、スペクトル制約、
および勾配を提供する。

## 10. 適用範囲：本ライブラリが何であり、何でないか

- 本ライブラリは新しい物理を生み出すもの**ではない**。セクターをもつ環における計算のための、検証済みの道具である。
  論文中の物理モデルは答えが既知の既知の系であり、道具の検証に用いている。
- 単一の大規模系（L = 30 での一つの基底状態、テンソルネットワーク、大規模回路のシミュレーション）に対しては、
  専用のパッケージ（QuSpin, ITensor/TeNPy, Qiskit）の方が適している。
- 本ライブラリが得意とするのは、明示的なセクター構造をもつ中程度のサイズの作用素を多数扱う場面である：乱れのアンサンブル、
  ランダムな状態やチャネルにわたる統計、スペクトル制約下での極値作用素、トレースの整合したセクター間チャネルなどを、
  自動微分および GPU と組み合わせて扱う。
- 元々の数学的な問題（トレース不等式、マイケルソン・コントラスト）は、モンテカルロ・サンプリングが失敗し、
  制約付き最適化が有効となる極値問題の一例である。
