# 写给数学家的物理：`torch_vn_algebra` 术语对照

*本文译自英文版；如有出入，以英文版为准。*

本指南面向具有算子代数背景、想了解本库及相关论文中物理模型含义的读者。全文均以作用在
H = ⊕_c C^{k_c} 上的代数 M = ⊕_c M_{k_c}(C) 来表述。对每个物理概念，我们都说明它在 M 中对应什么，
以及它在库中的位置。

---

## 0. 基本思想

物理对称性就是群 G 在 H 上的一个酉表示 π。与该对称性相容的一切（哈密顿量、时间演化、超选择定则下的
可观测量）都落在**交换子代数** π(G)' 中。由双交换子定理和 Schur 引理，

    H ≅ ⊕_λ V_λ ⊗ C^{m_λ},     π(G)' ≅ ⊕_λ M_{m_λ}(C),

因此 π(G)' 是有限维的第 I 型冯·诺依曼（von Neumann）代数。它的扇区就是不可约表示 λ，块的大小就是重数
m_λ，中心由“荷”的函数构成。所以，物理学家在对具有对称性的系统建模时，实际上就是在形如 (1) 的代数中
进行计算，只是通常不这样称呼它。对单个守恒量 Q（一个自伴算子）而言，扇区就是 Q 的本征值，块就是相应的
本征子空间。

这也回答了“为什么不直接用一个大矩阵？”这个问题。嵌入 M ⊂ M_N（N = Σk_c）是精确的，但会丢失
- **计算代价**：Σk_c³ 而不是 N³；若有 C 个相同大小的块，时间上相差 C² 倍；
- **测度**：M 的酉群是 Π U(k_c)，它在 U(N) 中是零测集。U(N) 中按 Haar 测度随机取的酉矩阵不在 M 中，
  而在 M_N 中走一步梯度也会离开 M；
- **迹**：M_N 上的迹在相差一个因子的意义下唯一，而 M 上的忠实迹构成 C 参数族 Σ w_c Tr_c。
  “保迹”以及对偶映射都依赖于这些权重；
- **中心**：扇区投影是系统的经典部分（见第 2 节）。条件概率和后选择都是涉及中心的运算，
  若只用一个矩阵，就得从块指标中把它们重新构造出来。

C = 1 的情形同样支持：这时就是 M_n 中的批量线性代数。

## 1. 态、可观测量与测量

| 物理 | 数学 | 库中对应 |
|---|---|---|
| 可观测量（能量、自旋、粒子数） | 自伴元 A ∈ M | `Operator` |
| 可能的测量结果 | A 的谱 | `eigh`, `eigenvalues` |
| （混合）态 | 正规正泛函 ω，ω(1) = 1；密度 ρ ≥ 0，Tr ρ = 1 | `DensityMatrix` |
| 纯态，“波函数” | 向量 ψ ∈ H，ρ = \|ψ⟩⟨ψ\|（极小投影） | `vector_in_sector`, `basis_state` |
| 期望值 | ω(A) = Tr(ρA) | `expectation` |
| 测得结果 λ 的概率 | ω(P_λ)，P_λ 为谱投影 | `apply_function` |
| 测量后的态（Lüders 规则） | ρ ↦ PρP / Tr(Pρ) | `lueders_update`, `condition_on` |
| 冯·诺依曼熵 | S(ρ) = −Tr ρ log ρ | `entropy` |
| 温度，热平衡态 | ρ = e^{−βH}/Tr e^{−βH}（吉布斯态 = KMS 态） | `gibbs_state` |
| 无穷高温 | 迹态 τ / τ(1) | `tracial_state` |

**三种迹的物理含义。**
- Tr_blunt（权重为 1）是 H 上的物理迹。归一化后它就是无穷高温态：
  全部 N 个基矢态等概率出现，扇区 c 的概率为 k_c/N。
- Tr_norm（权重为 1/k_c）：在每个扇区内部分别取均匀（微正则）态。
- τ_vN（权重为 1/(C k_c)）：各扇区微正则态的均匀混合。此时是每个
  *扇区*（而不是每个基矢态）的概率为 1/C。

任何态限制到中心上，都给出扇区上的一个经典概率分布
（`sector_probabilities`）。这就是物理学家所说的“荷为 q 的概率”。

## 2. 超选择、退相干、经典与量子

- **超选择定则**（Wick–Wightman–Wigner）：不同荷（电荷、费米子宇称）的态之间的叠加是不可观测的。
  用数学语言说，容许的可观测量构成荷的交换子代数，即代数 M，而不是整个 B(H)。
- **M 的中心**由那些可以无扰动地测量、并与一切元素对易的量组成，即“经典”变量。若所有 k_c = 1，
  系统是纯经典的（交换代数，也就是 C 个点上的概率空间）。若 C = 1，系统是纯量子的。一般情形则是
  两者的混合。
- **退相干 / 环境诱导超选择（einselection）**（Zurek）：与环境的相互作用压制非对角块
  ρ_{cd}，c ≠ d。这正是条件期望 E: B(H) → M，ρ ↦ Σ P_c ρ P_c，可观测量的有效代数随之缩小为 M。
  在本库中算子本来就位于 M 中，因此计算的起点就是这一条件期望的结果。

## 3. 封闭系统的动力学

| 物理 | 数学 | 库中对应 |
|---|---|---|
| 哈密顿量 | 自伴元 H ∈ M | — |
| 薛定谔（Schrödinger）方程 i dψ/dt = Hψ | ψ(t) = e^{−itH}ψ(0) | `dynamics.schrodinger`, `propagator` |
| 冯·诺依曼方程 dρ/dt = −i[H, ρ] | ρ(t) = U ρ U*，U = e^{−itH} | `von_neumann` |
| 海森堡（Heisenberg）绘景 | A(t) = U* A U（M 的一个自同构） | `solve_operator_ode` |
| 守恒量 | 满足 [H, Q] = 0 的 Q | 扇区 |

若 H ∈ M，则 e^{−itH} ∈ M，动力学永远不会离开各扇区。每个扇区独立演化，
指数函数也是逐块计算的。

## 4. 开放系统与信道

- **量子信道**是完全正的保迹映射（薛定谔绘景）。它的伴随映射（海森堡绘景）是完全正的、
  保单位的。Kraus 形式：
  Φ(ρ) = Σ_i K_i ρ K_i*。库中对应：`Channel`。
- **扇区间信道**（`InterSectorChannel`）描述改变荷的过程：
  粒子丢失、衰变、电子隧穿出去。其 Kraus 块为 K^{dc}: C^{k_c} → C^{m_d}。
  保迹性和对偶映射都依赖于输入端和输出端的迹权重，因此会出现
  因子 w_out/w_in。
- **Lindblad 方程**（GKSL）生成信道半群 e^{tL}：
  dρ/dt = −i[H, ρ] + Σ_j γ_j (L_j ρ L_j* − ½{L_j* L_j, ρ})。
  其中 L_j 称为“跳跃算符”，每一个描述环境作用于系统的一种方式。
  - **T1**（能量弛豫，振幅阻尼）：L = σ⁻ = |0⟩⟨1|，量子比特从激发态
    衰变到基态。激发数减少一，因此这是扇区**之间**的跳跃。
    例子：`site_amplitude_damping`, `lowering`。
  - **T2**（退相位）：L = σ^z。它是对角的，不改变扇区，只破坏
    相位。这是扇区**之内**的跳跃。
  - T1 和 T2 是每台量子计算机都会给出的标准相干时间。

## 5. 自旋链

- **单格点上的自旋 ½**：H_site = C²，基为 |↑⟩, |↓⟩（或 |1⟩, |0⟩）。Pauli 矩阵 σ^x, σ^y, σ^z；
  S^a = σ^a/2；S^± = S^x ± iS^y 为升降算符。
- **L 个自旋组成的链**：H = (C²)^{⊗L}，dim = 2^L。正是这种指数增长使物理学家离不开
  对称性。
- **XXZ 哈密顿量**：H = Σ_⟨ij⟩ [J/2 (S_i⁺S_j⁻ + S_i⁻S_j⁺) + JΔ S_i^z S_j^z] + Σ_i h_i S_i^z。
  第一项交换相邻的 ↑↓（“粒子跃迁”），第二项是它们之间的相互作用，第三项是
  外场。Δ = 1 即海森堡模型（一种磁体），Δ = 0 等价于自由费米子（通过
  Jordan–Wigner 变换），由此可以做精确检验。
- **守恒荷**：S^z_tot，或 N = ↑ 的个数（比特串的汉明重量）。H 的每一项
  都保持它不变，因此 H ∈ ⊕_{N=0}^{L} M_{C(L,N)}：各块的大小是二项式系数。
- **扇区融合**（`fused_tensor_product`）：在张量积下荷相加。这就是 U(1) 的融合
  规则：(⊕_q M_{n_q}) ⊗ (⊕_r M_{m_r}) ⊂ ⊕_s M_{Σ_{q+r=s} n_q m_r}。`SpinChain` 正是以这种方式
  逐个格点地构造其基。
- **动量**（`momentum_algebra`）：环形链还具有平移对称性 T（群 Z_L）。联合
  本征子空间 (N, k)（e^{ik} 为 T 的本征值）给出更细的分解，块的大小约缩小为原来的
  1/L。
- **基态**是 H 的最小本征值对应的本征向量，即零温下的
  行为。对于大块，用 Lanczos 方法求得（`krylov`）。
- 论文所检验的内容，以及它们为何是标准测试：
  - 海森堡环的基态能量（有已知精确值，Bethe 拟设）；
  - **Marshall 符号规则**：对二分晶格上的海森堡模型，基态的
    符号为 (−1)^{number of ↑ on one sublattice}。这是一个定理，因而是一个干净的检验；
  - **SU(2) 嵌套**：海森堡模型具有完整的 SU(2) 对称性，因此当 N < L/2 时，
    扇区 N 的谱包含在扇区 N+1 的谱之中（多重态）；
  - **畴壁融化**：|↑…↑↓…↓⟩ 在 Δ = 0 时以已知的轮廓扩散；
  - **Peschel 公式**：由关联矩阵求自由费米子的纠缠熵。
- **无序与混沌**（`random_field_heisenberg`, `level_spacing_ratio`）：随机场
  h_i ∈ [−W, W]。W 较小时系统是“混沌”的，能级像 GOE 中那样相互排斥，⟨r⟩ ≈ 0.53。
  W 较大时系统发生局域化（多体局域化，MBL），能级像 Poisson 过程那样相互独立，
  ⟨r⟩ ≈ 0.386。能级统计只有在**单个扇区内部**才有意义：把不同扇区混在一起会人为地
  产生 Poisson 统计。这是支持在带扇区结构的代数中进行计算的一个很好的
  物理论据。

## 6. 纠缠与子系统

- 复合系统 A+B：H_A ⊗ H_B，代数 M_A ⊗ M_B。
- **约化态** ρ_A = Tr_B ρ 是泛函 ω 在子代数 M_A ⊗ 1 上的限制。
  用密度矩阵的语言说，它是一个条件期望（偏迹）。库中对应：
  `partial_trace`, `reduced_state`。
- 纯态 ρ 的**纠缠熵** S(ρ_A) 度量 A 与 B 之间的量子关联。
- **Page 公式**：随机纯态中子系统平均熵的精确值。它用来检验
  采样器是否服从 Haar 分布。
- **对称性分辨纠缠**：若荷守恒，则 ρ_A 是块对角的，其熵
  分解为“经典”部分（中心上分布的熵）与“量子”部分
  （各块熵的平均）。这是对中心的直接应用。

## 7. 量子计算

- **量子比特** = C²，n 个量子比特 = (C²)^{⊗n}；**量子门**是一个酉算子；**量子线路**是一串门的乘积；
  在计算基下的**测量**使用 σ^z 的谱投影。
- **QAOA**（量子近似优化算法 / 交替算子拟设）：交替作用 e^{−iγ H_C}（H_C 是
  对角的，编码目标函数）和 e^{−iβ H_M}（“混合算子”）。对于带有“恰好 k 个 1”约束的问题
  （从 n 个对象中选 k 个），采用 **XY 混合算子** Σ(X_iX_j + Y_iY_j) =
  2Σ(σ⁺σ⁻ + h.c.)。它保持汉明重量不变，因此整个线路都位于 ⊕_N M_{C(n,N)} 中，
  而可行解恰好构成扇区 N = k。
- **噪声**：T1 会离开可行扇区（丢失一个 1），T2 则不会。
- **后选择**：测量汉明重量并舍弃不符合的运行结果。这就是以**中心**投影 P_k
  为投影的 Lüders 规则：ρ ↦ P_kρP_k / Tr(P_kρ)，成功概率为 ω(P_k)。
  `ex9_qaoa_xy_mixer.py` 做的正是这件事。对于纯 T1 噪声，后选择能精确恢复理想态
  （F = 1），因为每次 T1 跳跃都会离开该扇区。
- 无退相干子空间与算子代数纠错：受保护的信息被编码在噪声不触及的某个代数的
  一个块（或一个块的一个张量因子）中。这同样
  是第 I 型代数的语言（Knill–Laflamme–Viola，Bény–Kempf–Kribs）。

## 8. 随机矩阵：实与复

这与参数 `complex_valued` 直接相关。
- **反酉对称性**指时间反演 T。若 T² = 1（无自旋粒子，无磁场），
  则在适当的基下 H 是**实**的：GOE、正交系综、COE。实数运算就够了；它
  使内存减半，速度也更快（见论文中的计时表）。
- 若没有这种对称性（磁场、复相位、动量 k ≠ 0, π），H 是复的：GUE、CUE。
  此时必须使用复数。
- 若 T² = −1（具有自旋–轨道耦合的半整数自旋），则属于四元数情形：GSE、CSE。
- 实外场下的 XXZ 模型是实的。k ∉ {0, π} 的动量扇区是复的。动力学
  e^{−itH} 总是复的，即使 H 是实的也如此。这就是论文中“何种情形下什么就够用”的那张表。
- 当微小差别至关重要时需要双精度：简并谱、精度要求达到
  1e−12 的恒等式检验、长时间演化、多步 Lanczos。对大量样本做统计时，单精度（以及 tensor core 上的 TF32）
  就足够了。

## 9. 机器学习

等变线性层是一个与某个群表示对易的映射 W: V → V（卷积对应平移，
图网络对应置换，分子对应旋转）。由 Schur 引理，这样的 W 构成的空间
是 ⊕_λ M_{m_λ}，其中 m_λ 为重数，因此等变层由形如 (1) 的代数中的一个
元素来参数化。本库为这类参数化提供按正确测度的随机初始化、
谱约束以及梯度。

## 10. 适用范围：本库是什么，不是什么

- 本库**不**产生新的物理。它是在带扇区结构的代数中进行计算的、经过验证的
  工具。论文中的物理模型都是已知答案的已知系统，用来检验
  这一工具。
- 对于单个大系统（L = 30 时的单个基态、张量网络、大规模线路模拟），
  专门的软件包（QuSpin、ITensor/TeNPy、Qiskit）是更好的选择。
- 本库的定位是大量中等规模、具有显式扇区结构的算子：无序系综、
  随机态与随机信道上的统计、谱约束下的极值算子、迹相容的
  扇区间信道，并结合自动微分与 GPU。
- 最初的数学问题（迹不等式、Michelson 对比度）是一个
  极值问题的例子：Monte Carlo 采样在此失效，而约束优化行之有效。
