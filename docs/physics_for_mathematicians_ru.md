# Физика для математика: словарь к `torch_vn_algebra`

Этот текст для автора-математика, которому нужно понимать и защищать физическую часть статьи.
Всё сформулировано на языке алгебры
M = ⊕_c M_{k_c}(C) на H = ⊕_c C^{k_c}. Для каждого физического понятия указано, чем оно является в M
и где оно лежит в библиотеке.

---

## 0. Главная мысль в одной фразе

Физическая симметрия — это унитарное представление группы G на H. Всё, что с симметрией
совместимо (гамильтониан, эволюция, наблюдаемые при правиле суперотбора), лежит в **коммутанте**
π(G)'. По теореме о двойном коммутанте и лемме Шура

    H ≅ ⊕_λ V_λ ⊗ C^{m_λ},     π(G)' ≅ ⊕_λ M_{m_λ}(C),

то есть π(G)' — конечномерная алгебра фон Неймана типа I. Её секторы — неприводимые
представления λ, размеры блоков — кратности m_λ, центр — функции от «зарядов».
Поэтому физик, моделирующий систему с симметрией, всегда считает в алгебре вида (1),
хотя обычно этого так не называет. Для одной сохраняющейся величины Q (самосопряжённого оператора)
секторы — собственные значения Q, а блоки — собственные подпространства.

Это главный аргумент статьи. Отсюда же ответ на вопрос «почему не взять одну большую матрицу»:
вложение M ⊂ M_N (N = Σk_c) точное, но при нём теряются
- **стоимость**: Σk_c³ против N³; при C равных блоках это выигрыш в C² по времени;
- **мера**: группа унитарных элементов M — это Π U(k_c), подмножество U(N) меры нуль. Хааровская
  унитарная матрица из U(N) не лежит в M, а градиентный шаг в M_N выводит из M;
- **следы**: на M_N след единственен с точностью до множителя, на M — C-параметрическое семейство
  Σ w_c Tr_c. От выбора весов зависят «сохранение следа» и двойственные отображения;
- **центр**: проекторы на секторы — это классическая часть системы (раздел 2). Условные
  вероятности и постселекция — операции с центром, и при хранении одной матрицей их надо
  восстанавливать по индексам блоков.

Сам случай C = 1 библиотека тоже поддерживает: это просто пакетная линейная алгебра в M_n.

## 1. Состояния, наблюдаемые, измерения

| физика | математика | в библиотеке |
|---|---|---|
| наблюдаемая (энергия, спин, число частиц) | самосопряжённый A ∈ M | `Operator` |
| возможные значения при измерении | спектр A | `eigh`, `eigenvalues` |
| состояние (смешанное) | нормальное положительное функционал ω, ω(1)=1; плотность ρ ≥ 0, Tr ρ = 1 | `DensityMatrix` |
| чистое состояние, «волновая функция» | вектор ψ ∈ H, ρ = \|ψ⟩⟨ψ\| (минимальная проекция) | `vector_in_sector`, `basis_state` |
| среднее значение | ω(A) = Tr(ρA) | `expectation` |
| вероятность исхода λ | ω(P_λ), P_λ — спектральный проектор | `apply_function` |
| состояние после измерения (правило Людерса) | ρ ↦ PρP / Tr(Pρ) | `lueders_update`, `condition_on` |
| энтропия фон Неймана | S(ρ) = −Tr ρ log ρ | `entropy` |
| «температура», тепловое состояние | ρ = e^{−βH}/Tr e^{−βH} (состояние Гиббса = KMS) | `gibbs_state` |
| бесконечная температура | следовое состояние τ / τ(1) | `tracial_state` |

**Физический смысл трёх следов.** Это удобно знать для ответа рецензенту.
- Tr_blunt (веса 1) — физический след на H. Нормированный, он даёт «бесконечную температуру»:
  все N базисных состояний равновероятны, сектор c имеет вероятность k_c/N.
- Tr_norm (веса 1/k_c): в каждом секторе отдельно — равномерное (микроканоническое) состояние.
- τ_vN (веса 1/(C k_c)) — равномерная смесь микроканонических состояний секторов. Каждый
  *сектор* (а не базисное состояние) имеет вероятность 1/C.

Ограничение любого состояния на центр — классическое распределение вероятностей на секторах
(`sector_probabilities`). Именно это физики называют «вероятностью иметь заряд q».

## 2. Суперотбор, декогеренция, классическое и квантовое

- **Правило суперотбора** (Вик–Вайтман–Вигнер): суперпозиции состояний с разным зарядом
  (электрическим зарядом, чётностью фермионов) ненаблюдаемы. Математически допустимые наблюдаемые
  образуют коммутант заряда, то есть алгебру M, а не всё B(H).
- **Центр M** — это величины, которые измеряются без возмущения и коммутируют со всем, то есть
  «классические» переменные. Если M = ⊕ M_1 (все k_c = 1), система полностью классическая
  (коммутативная алгебра = вероятностное пространство на C точках). Если C = 1, система полностью
  квантовая. Общий случай — гибрид.
- **Декогеренция / эйнселекция** (Зурек): взаимодействие с окружением гасит внедиагональные блоки
  ρ_{cd}, c ≠ d. Это условное ожидание E: B(H) → M, ρ ↦ Σ P_c ρ P_c. Эффективная
  алгебра наблюдаемых сужается до M. В библиотеке операторы всегда уже лежат в M, то есть
  результат этого условного ожидания — исходная точка вычислений.

## 3. Замкнутая динамика

| физика | математика | в библиотеке |
|---|---|---|
| гамильтониан | самосопряжённый H ∈ M | — |
| уравнение Шрёдингера i dψ/dt = Hψ | ψ(t) = e^{−itH}ψ(0) | `dynamics.schrodinger`, `propagator` |
| уравнение фон Неймана dρ/dt = −i[H, ρ] | ρ(t) = U ρ U*, U = e^{−itH} | `von_neumann` |
| картина Гейзенберга | A(t) = U* A U (автоморфизм M) | `solve_operator_ode` |
| сохраняющаяся величина | Q с [H, Q] = 0 | секторы |

Если H ∈ M, то e^{−itH} ∈ M, и динамика не выводит из секторов. Поэтому каждый сектор
эволюционирует независимо, и экспоненту можно считать по блокам.

## 4. Открытые системы и каналы

- **Квантовый канал** — вполне положительное отображение, сохраняющее след (в картине
  Шрёдингера). Его сопряжённое (картина Гейзенберга) — вполне положительное, сохраняющее единицу.
  Представление Крауса: Φ(ρ) = Σ_i K_i ρ K_i*. В библиотеке: `Channel`.
- **Канал между секторами** (`InterSectorChannel`): процесс, меняющий заряд, например потеря
  частицы, распад, туннелирование электрона. Блоки Краусa K^{dc}: C^{k_c} → C^{m_d}. Сохранение следа
  и двойственное отображение зависят от весов следа на входе и выходе, отсюда множители w_out/w_in.
- **Уравнение Линдблада** (ГКСЛ) — генератор полугруппы каналов e^{tL}:
  dρ/dt = −i[H, ρ] + Σ_j γ_j (L_j ρ L_j* − ½{L_j* L_j, ρ}).
  L_j — «операторы скачков»: каждый описывает один канал взаимодействия с окружением.
  - **T1** (энергетическая релаксация, амплитудное затухание): L = σ⁻ = |0⟩⟨1|, кубит падает
    из возбуждённого состояния в основное. Число возбуждений уменьшается на 1, то есть это
    скачок **между** секторами. Пример: `site_amplitude_damping`, `lowering`.
  - **T2** (дефазировка): L = σ^z. Оператор диагонален, сектор не меняется, гасятся только фазы.
    Это скачок **внутри** сектора.
  - T1 и T2 — стандартные времена жизни кубита в любом квантовом компьютере.

## 5. Спиновые цепочки

- **Спин ½ на узле**: H_site = C², базис |↑⟩, |↓⟩ (или |1⟩, |0⟩). Матрицы Паули σ^x, σ^y, σ^z;
  S^a = σ^a/2; S^± = S^x ± iS^y — повышающий и понижающий операторы.
- **Цепочка из L спинов**: H = (C²)^{⊗L}, dim = 2^L. Это и есть экспоненциальный рост, из-за
  которого физикам нужны симметрии.
- **Гамильтониан XXZ**: H = Σ_⟨ij⟩ [J/2 (S_i⁺S_j⁻ + S_i⁻S_j⁺) + JΔ S_i^z S_j^z] + Σ_i h_i S_i^z.
  Первое слагаемое переставляет соседние ↑↓ («прыжок частицы»), второе — их взаимодействие,
  третье — внешнее поле. Δ = 1 — модель Гейзенберга (магнетик), Δ = 0 — свободные фермионы
  (через преобразование Йордана–Вигнера, отсюда точные проверки).
- **Сохраняющийся заряд**: S^z_tot, или N = число ↑ (вес Хэмминга битовой строки). Все слагаемые H
  его сохраняют, поэтому H ∈ ⊕_{N=0}^{L} M_{C(L,N)}. Блоки биномиальные.
- **Слияние секторов** (`fused_tensor_product`): заряды при тензорном произведении складываются.
  Это правило Литтлвуда–Ричардсона для абелевой группы U(1): (⊕_q M_{n_q}) ⊗ (⊕_r M_{m_r}) ⊂
  ⊕_s M_{Σ_{q+r=s} n_q m_r}. Ровно так `SpinChain` строит базис, итерируя по узлам.
- **Импульс** (`momentum_algebra`): у кольца есть ещё симметрия сдвига T (группа Z_L). Совместные
  собственные подпространства (N, k) с e^{ik} = собственным значением T дают более мелкое разбиение.
  Блоки получаются примерно в L раз меньше.
- **Основное состояние** — собственный вектор с наименьшим собственным значением H, по сути
  поведение при нулевой температуре. Для больших блоков его ищут методом Ланцоша (`krylov`).
- Что проверяется в статье и почему это стандарт:
  - энергии кольца Гейзенберга (известные точные числа, анзац Бете);
  - **правило знаков Маршалла**: для Гейзенберга на двудольной решётке основное состояние
    имеет знаки (−1)^{число ↑ на нечётных узлах}. Это теорема, удобный тест;
  - **SU(2)-вложенность**: модель Гейзенберга имеет полную симметрию SU(2), поэтому спектр
    сектора N содержится в спектре сектора N+1 (мультиплеты);
  - **таяние доменной стенки**: |↑…↑↓…↓⟩ при Δ = 0 расплывается с известным профилем;
  - **формула Пешеля**: энтропия запутанности свободных фермионов через корреляционную матрицу.
- **Беспорядок и хаос** (`random_field_heisenberg`, `level_spacing_ratio`): случайные поля h_i ∈ [−W, W].
  При малом W система «хаотична» и уровни отталкиваются как у GOE, ⟨r⟩ ≈ 0.53. При большом W
  наступает локализация (многочастичная локализация, MBL), уровни независимы как у Пуассона,
  ⟨r⟩ ≈ 0.386. Статистику уровней имеет смысл считать **только внутри одного сектора**: смешение
  секторов искусственно даёт Пуассона. Это хороший физический аргумент за алгебру с секторами.

## 6. Запутанность и подсистемы

- Составная система A+B: H_A ⊗ H_B, алгебра M_A ⊗ M_B.
- **Редуцированное состояние** ρ_A = Tr_B ρ — это ограничение функционала ω на подалгебру
  M_A ⊗ 1. На языке плотностей это условное ожидание (частичный след). В библиотеке: `partial_trace`,
  `reduced_state`.
- **Энтропия запутанности** S(ρ_A) для чистого ρ — мера квантовой корреляции A и B.
- **Формула Пейджа**: средняя энтропия подсистемы случайного чистого состояния, точная формула.
  Это проверка хааровости сэмплера.
- **Симметрийно-разрешённая запутанность**: если заряд сохраняется, то ρ_A ∈ ⊕_q M (блочная), и
  энтропия раскладывается в «классическую» часть (энтропия распределения на центре) и
  «квантовую» (среднее энтропий блоков). Это прямое приложение структуры центра.

## 7. Квантовые вычисления

- **Кубит** = C², n кубитов = (C²)^{⊗n}; **гейт** = унитарный оператор; **схема** = произведение
  гейтов; **измерение** в вычислительном базисе = спектральные проекторы σ^z.
- **QAOA** (quantum approximate / alternating operator ansatz): чередование e^{−iγ H_C}
  (H_C диагонален и кодирует целевую функцию) и e^{−iβ H_M} («миксер»). Для задач с ограничением
  «ровно k единиц» (выбор k элементов из n) берут **XY-миксер** Σ(X_iX_j + Y_iY_j) = 2Σ(σ⁺σ⁻ + h.c.).
  Он сохраняет вес Хэмминга, поэтому вся схема лежит в ⊕_N M_{C(n,N)}, и допустимые решения —
  ровно сектор N = k.
- **Шум**: T1 выводит из допустимого сектора (теряет единицу), T2 нет.
- **Постселекция**: измерить вес Хэмминга и отбросить неправильные запуски. Это правило Людерса
  с **центральным** проектором P_k: ρ ↦ P_kρP_k / Tr(P_kρ). Вероятность успеха — ω(P_k).
  Ровно это делает `ex9_qaoa_xy_mixer.py`. Для чистого T1 постселекция возвращает
  точное идеальное состояние (F = 1), потому что каждый скачок T1 уводит из сектора.
- Подпространства без декогеренции и операторная коррекция ошибок: защищённая информация
  кодируется в одном блоке (или в одном множителе блока) алгебры, которую шум не трогает.
  Это тоже язык алгебр типа I (Книлл–Лафламм–Виола, Бени–Кемпф–Крибс).

## 8. Случайные матрицы и вещественное / комплексное

Это напрямую связано с параметром `complex_valued`.
- **Антиунитарная симметрия** — обращение времени T. Если T² = 1 (бесспиновые частицы, нет
  магнитного поля), то в подходящем базисе H **вещественна**: GOE, ансамбль ортогональных матриц,
  COE. Вещественной арифметики достаточно, это вдвое меньше памяти и примерно в 2–4 раза быстрее.
- Если симметрии T нет (магнитное поле, комплексные фазы, импульс k ≠ 0, π), H комплексная: GUE,
  CUE. Нужны комплексные числа.
- Если T² = −1 (полуцелый спин со спин-орбитой), то это кватернионный случай: GSE, CSE.
- Модель XXZ с вещественными полями вещественна. Импульсные секторы при k ∉ {0, π} комплексны.
  Динамика e^{−itH} всегда комплексна, даже при вещественном H. Это и есть таблица
  «когда что достаточно» в статье.
- Двойная точность нужна, когда важны мелкие разности: вырожденные спектры, проверка тождеств
  до 1e−12, длинные эволюции, ланцош с большим числом шагов. Одинарной (и TF32 на тензорных
  ядрах) хватает для статистики по многим сэмплам.

## 9. Машинное обучение

Эквивариантный линейный слой — отображение W: V → V, коммутирующее с представлением группы
(сдвиги для свёрток, перестановки для графовых сетей, вращения для молекул). По лемме Шура
пространство таких W — это ⊕_λ M_{m_λ} с кратностями m_λ. То есть параметризация
эквивариантного слоя — элемент алгебры (1). Библиотека даёт для таких слоёв случайную
инициализацию с нужной мерой, спектральные ограничения и градиенты.

---

## 10. Что честно говорить физику-рецензенту

- Библиотека **не делает новую физику**. Это проверенный инструмент для вычислений в алгебрах с
  секторами. Физические модели в статье — известные системы с известными ответами,
  на которых инструмент проверен.
- Для одной большой системы (одно основное состояние на L = 30, тензорные сети, симуляция больших
  схем) специализированные пакеты (QuSpin, ITensor/TeNPy, Qiskit) лучше, и в статье это сказано.
- Ниша — много операторов среднего размера с явной секторной структурой: ансамбли по беспорядку,
  статистика по случайным состояниям и каналам, поиск экстремальных операторов при спектральных
  ограничениях, каналы между секторами с правильными следами. Плюс автодифференцирование и GPU.
- Собственный математический вопрос (неравенства для следов, контраст Майкельсона) — это пример
  «экстремальной» задачи, где выборка Монте-Карло не работает, а условная оптимизация работает.
