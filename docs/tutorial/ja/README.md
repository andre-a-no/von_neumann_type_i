# 有限次元フォン・ノイマン環：`torch_vn_algebra` による講義

本講義では、有限次元フォン・ノイマン環、すなわち環
$\bigoplus_cM_{k_c}(\mathbb C)$ の理論を、量子物理学、量子情報、ランダム行列理論および機械学習への応用とともに解説し、各段階で `torch_vn_algebra` を用いてそれらをどのように計算するかを示す。

本講義は二種類の読者を同時に想定して書かれている。

- **数学者**には、用いるすべての結果について完全な証明を与える。標準的な線形代数、代数学の基本定理、および解析学・確率論の初等的事実（極限、凸性、ガウス分布の積率母関数）を除き、証明なしに引用するものはない。ある結果を証明より前に述べる場合、あるいは適用するだけの場合には、その旨を明記する。
- **物理学者と技術者**には、*物理的意味* と題した囲みで各概念の物理的意味を与え、また自分の用途に合わせて改変できる動作するコードを与える。

各章は同じ構成をとる。すなわち、証明付きの理論、各結果に対応するライブラリのコード、厳密な結果（定理、閉じた公式、あるいは独立な計算）によるコードの検証、同じ作業のための標準的な道具を挙げる節 *比較の対象*、そして解答付きの演習問題である。

本講義のすべてのコードはテストスイート（`tests/test_tutorial.py`）によって実行されるので、どの例もライブラリの現行版で動作する。

## 予備知識

$\mathbb C$ 上の線形代数（固有値、内積、ユニタリ行列）、初等的な確率論、および Python。物理学と関数解析の知識は仮定しない。

## コードの実行方法

```bash
pip install -e .                # from the root of the repository
python -m pytest tests/test_tutorial.py -q
```

各章のコードブロックは、順番どおりに一つの Python セッションまたは Jupyter ノートブックに貼り付けて実行できる。同じ章のブロックは変数を共有する。
