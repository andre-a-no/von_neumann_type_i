# Конечномерные алгебры фон Неймана: курс с `torch_vn_algebra`

Этот курс излагает теорию конечномерных алгебр фон Неймана, то есть алгебр
$\bigoplus_cM_{k_c}(\mathbb C)$, вместе с их приложениями в квантовой физике, квантовой
теории информации, теории случайных матриц и машинном обучении, и на каждом шаге
показывает, как проводить с ними вычисления в `torch_vn_algebra`.

Курс рассчитан сразу на два круга читателей:

- **Математики** найдут полные доказательства всех используемых результатов. Без
  доказательства не приводится ничего, кроме стандартной линейной алгебры, основной теоремы
  алгебры и элементарных фактов анализа и теории вероятностей (пределы, выпуклость,
  производящая функция моментов гауссовского распределения); если результат формулируется
  раньше, чем доказывается, или только применяется, об этом говорится явно.
- **Физики и инженеры** найдут физический смысл каждого понятия во врезках с пометкой
  *Физический смысл*, а также работающий код, который можно приспособить к своим задачам.

Главы 1–12 устроены одинаково: теория с доказательствами; код библиотеки для каждого
результата; проверка кода по точному результату (теореме, явной формуле или независимому
вычислению); раздел *С чем сравнивать*, где названы стандартные инструменты для той же
задачи; упражнения с решениями.

Весь код курса выполняется набором тестов (`tests/test_tutorial.py`), поэтому каждый
пример работает с текущей версией библиотеки.

## Предварительные сведения

Линейная алгебра над $\mathbb C$ (собственные значения, скалярные произведения, унитарные
матрицы), основы теории вероятностей и Python. Знание физики и функционального анализа не
предполагается.

## Как запускать код

```bash
pip install -e .                # from the root of the repository
python -m pytest tests/test_tutorial.py -q
```

Все блоки кода главы можно по порядку вставить в один сеанс Python или в блокнот
Jupyter. Блоки одной главы используют общие переменные.
