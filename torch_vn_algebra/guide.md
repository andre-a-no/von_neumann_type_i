# torch_vn_algebra: guide for AI coding assistants

This file is written for language models that write code with this library, and for people who want the essentials
on one page. It ships inside the package. Print it with `python -m torch_vn_algebra.guide`.

`python -m torch_vn_algebra.guide --api [module]` prints the exact signature and the first docstring paragraph of
every public class, method and function. The list is built from the installed version, so it is authoritative.
Do not guess a name or an argument: look it up there. The code blocks below are run by the test suite
(`tests/test_guide.py`).

## 1. What the library computes

A finite-dimensional Type I von Neumann algebra is a direct sum of full matrix algebras:

    M = M_{k_1}(C) ⊕ … ⊕ M_{k_C}(C),  acting on  H = C^{k_1} ⊕ … ⊕ C^{k_C}.

The summands are called *sectors* (symmetry, charge or superselection sectors). The library computes with batches
of elements of such an algebra on CPU or GPU, differentiably:
- operators;
- states (density matrices);
- channels, both within one algebra and between algebras;
- dynamics;
- spin and anyon chains in their symmetry sectors;
- inclusions and conditional expectations;
- decompositions of the algebra generated by matrices or by a group.

Use it when the block structure is part of the problem: many sectors of different sizes, many samples or starts at
once, or quantities defined by the algebra (its traces, centre, channels between sectors).

Do not use it for:
- one dense matrix at a time (use `torch.linalg`);
- sparse systems beyond about 10^6 states (use QuSpin);
- tensor networks (use ITensor or TeNPy);
- adaptive ODE solvers or quantum trajectories (use QuTiP or dynamiqs; `interop` converts to both).

## 2. Data model

- `alg = TypeIAlgebra(n_factors, k_factors, complex_valued=True, precision='single', device=None, layout='auto')`.
  - `k_factors` are the block sizes.
  - `n_factors` (with `n_c ≥ k_c`) are nominal sizes; pass the same list unless you mean a corner of a larger algebra.
  - Attributes: `alg.C` (number of sectors), `alg.k_factors`, `alg.k_max`, `alg.dtype`, `alg.device`.
- An `Operator` has two storage layouts (`alg.layout`):
  - `'padded'`: one tensor `(batch, C, k_max, k_max)`. Block `c` is the top-left `k_c × k_c` corner of
    `op.matrix[:, c]`; **the rest is zero padding**.
  - `'packed'`: one tensor `(batch, n_g, k_g, k_g)` per block size, in the order of `alg.size_groups`, with no
    padding.
  - `layout='auto'` (default) packs when the padding would fill at least half of the padded tensor (for example
    the full algebra of a `SpinChain`). The environment variable `TORCH_VN_ALGEBRA_LAYOUT` overrides the default.
  - Results do not depend on the layout. **`op.matrix` is always the padded tensor**; in the packed layout it is a
    copy assembled on demand, which costs memory and must not be modified in place.
  - Read blocks with `op.block(c)` (`(batch, k_c, k_c)`) or `op.parts`, which work in both layouts and never pad.
  - Build operators with `alg.from_blocks([block_1, …, block_C])` (each block `(k_c, k_c)` or `(batch, k_c, k_c)`),
    `alg.from_parts(parts)`, or `alg.operator(padded_tensor)`.
- Batches: a batch of 1 broadcasts against a batch of B.
  - Every factory takes its own `batch_size`.
  - The `batch_size` argument of `TypeIAlgebra` only concerns its Hilbert-space bases.
- Number field and precision are two independent switches:
  - `complex_valued=False` gives a real algebra: orthogonal groups, GOE. Complex input is rejected there.
  - `precision='double'` gives float64 / complex128.
  - `alg.like(precision='double')` gives the same sectors with another field, precision or device, and
    `op.cast(alg2)` moves an operator there.
  - Operators of different dtypes cannot be combined: cast first.
- Laziness: `X @ Y`, `X + Y`, `X * s`, `X.adjoint()` and functional calculus build a recipe. It is evaluated once, and
  cached, when `.matrix` or a scalar is requested. Gradients flow through all of it (autograd).
- Some types are subclasses of `Operator`:
  - `states.DensityMatrix`: positive, with `Tr_blunt = 1`.
  - Channels map operators to operators: `Channel` preserves the sectors; `InterSectorChannel` maps between sectors
    or between algebras.

## 3. Conventions that differ from what you may expect

The library has three traces (methods of `Operator`, each returning a tensor of shape `(batch,)`, complex in a complex
algebra; take `.real`):

| method | formula | meaning |
|---|---|---|
| `Tr_blunt()` | Σ_c Tr A_c | the trace of the matrix on H; densities of states refer to this one |
| `Tr_norm()` | Σ_c Tr A_c / k_c | every block normalised, summed |
| `tau_vN()` | (1/C) Σ_c Tr A_c / k_c | the tracial state with equal sector weights |

- **Properties versus methods.**
  - Properties: `trace` (= Tr_blunt), `lambda_max`, `lambda_min`, `michelson_contrast`, `inv`, `matrix`,
    `is_self_adjoint`, `is_positive`.
  - Methods: `operator_norm()`, `trace_norm()`, `frobenius_norm()`, `eigenvalues()`, `eigh()`, `sqrt()`, `log()`,
    `power(p)`, `expm(s)`, `entropy()`, `adjoint()`, `inverse(tol)`, `apply_function(f)`.
- **Per-sector quantities without padding:** `op.sector_traces()` (`(batch, C)`) and `op.block(c)`. Prefer them
  over slicing `op.matrix`, which pads a packed operator.
- **Spectra are per sector.**
  - `op.eigenvalues()` returns a *list* of C tensors `(batch, k_c)`.
  - Never call `torch.linalg.eigvalsh(op.matrix)`: the zero padding adds spurious zero eigenvalues to the smaller
    blocks.
- **`apply_function(f)`** applies `f` elementwise to the eigenvalues of all blocks of one size at once, as a
  `(batch, n·k_c)` tensor. Per-sample parameters must have shape `(batch, 1)`. Use `per_block=True` when `f` must
  see one block per row.
- **Expectations.**
  - Use `states.trace_of_product(rho, A)` (O(k²)) or `rho.expectation(A)`, not `(rho @ A).Tr_blunt()` (O(k³)).
  - `rho.sector_probabilities()` gives `p_c = Tr rho_c`, shape `(batch, C)`.
- **Channels preserve sectors unless they are `InterSectorChannel`s.**
  - A `Channel` has Kraus operators of shape `(batch, r, C, k_max, k_max)`. `channel(rho)` is the Schrödinger
    picture; `channel.adjoint()` is the Heisenberg picture.
  - Maps between different algebras, or jumps between sectors (particle loss, partial trace), are
    `InterSectorChannel`s. Their dual depends on the trace: `adjoint(trace='blunt' | 'norm' | 'tau_vN')`.
- **Dynamics.**
  - State vectors have the block layout `(batch, C, k_max)`.
  - Unitary dynamics needs `complex_valued=True`.
  - `lindblad_evolve` returns a list of states, one per time.
  - `dynamics.lindblad_channel(alg, H, jumps, t)` is the exact `exp(tL)` as a `Channel`.
- **Spin chains use `precision='double'` by default.** `TypeIAlgebra` uses `'single'`.
  - In a `SpinChain(L)` the sector `N` is the number of up spins, with dimension binom(L, N).
  - `sector=N` gives a single-sector operator, `sector=None` the full algebra.
- **Run-time and memory safeguards.**
  - Large batched decompositions warn (`cost.CostWarning`) or raise `cost.InsufficientMemoryError` before they start.
  - `cost.set_limits(...)` changes the thresholds and `with cost.disabled():` switches them off; do not catch and
    ignore the error.

## 4. From a task to the function

| task | use |
|---|---|
| random positive / self-adjoint operator with a given spectrum | `alg.operator_from_eigenvalues(sampler, batch_size, force_positive=True, force_self_adjoint=True)` |
| Haar unitary in the algebra | `alg.random_unitary_operator(batch_size)`; on U(n): `alg.random_unitary(n, measure)` |
| random state, Gibbs state | `states.random_density_matrix(alg, batch_size, rank=None, measure='hs' \| 'bures')`, `states.gibbs_state(H, beta)` |
| entropy, fidelity, trace distance, relative entropy | `states.von_neumann_entropy`, `states.fidelity`, `states.trace_distance`, `states.relative_entropy` |
| Rényi divergences, recovery maps | `divergences.sandwiched_renyi_divergence`, `petz_renyi_divergence`, `petz_recovery` |
| standard channels | `channels.dephasing_channel`, `depolarizing_channel`, `amplitude_damping_channel`, `unitary_channel`, `kraus_channel`, `random_channel` |
| channel between sectors or algebras | `channels.InterSectorChannel.from_blocks(alg_in, alg_out, {(d, c): kraus})`, `random_inter_sector_channel` |
| tensor product, partial trace | `composite.tensor_product`, `fused_tensor_product` (charge conservation), `kron`, `partial_trace` |
| Schrödinger / Lindblad dynamics | `dynamics.schrodinger`, `von_neumann`, `lindblad_evolve`, `lindblad_channel`, `propagator` |
| spin-1/2 chain in U(1) sectors | `SpinChain(L, boundary)`: `xxz`, `heisenberg`, `random_field_heisenberg`, `reduced_state`, `entanglement_entropy` |
| sectors too large for dense matrices | `chain.xxz_sparse(...)` + `krylov.ground_state`, `krylov.lowest_eigenvalues`, `krylov.evolve` |
| any operator known through H·v | `krylov.MatrixFreeOperator(fn, dim, batch_size)`, `SparseSectorHamiltonian.from_coo`, `krylov.combine` |
| quantum trajectories (Monte Carlo wave functions) | `dynamics.trajectories(psi0 or rho0, H, jumps, times, n_traj=...)` → `.mean(A)`, `.density(i)` |
| SU(2) multiplets, Clebsch–Gordan | `SU2Chain`, `su2.clebsch_gordan` |
| algebra generated by matrices or a group, commutant | `decompose.from_generators`, `decompose.from_group`, `commutant_basis`, `twirl` |
| subalgebra, conditional expectation, Jones index | `inclusions.Inclusion(N, M, matrix)`, `.conditional_expectation('markov')`, `.index()` |
| POVM, instrument, sampling, Fisher information | `measurement.POVM`, `PVM`, `Instrument`, `fisher_information` |
| projections, spectral measure, measures on projections | `projections.join`, `meet`, `spectral_measure`, `ProjectionMeasure` |
| optimise over unitaries / positive operators / channels | `optimize.UnitaryParam`, `PositiveParam`, `StinespringParam`, `LindbladParam`, then `optimize.extremize` or `optimize.fit` |
| channels as `torch.nn` layers | `learn.ChannelLayer`, `UnitaryLayer`, `LindbladLayer`, `Residual`, `PostSelect`, `FeedForward` |
| continuous centre (Brillouin zone, parameter space) | `DirectIntegral.torus`, `grid`, `monte_carlo`; `.field`, `.trace` |
| anyon chains, Temperley–Lieb | `AnyonChain(k, L)`: `generator`, `hamiltonian`, `low_energies`, `inclusion` |
| N two-level systems, permutation symmetry | `permutational.PermutationalSystem`, `PermutationalLindbladian` |
| Jordan algebras | `jordan.jordan_algebra_generated`, `SpinFactor` |
| QuTiP / dynamiqs / dense matrices | `interop.to_qutip`, `from_qutip`, `to_dense`, `from_dense`, `jumps_to_qutip` |

## 5. Recipes

### Operators and the three traces

```python
import torch
from torch_vn_algebra import TypeIAlgebra, states

alg = TypeIAlgebra([2, 3], [2, 3], precision='double')          # M_2 ⊕ M_3
A = alg.operator_from_eigenvalues(lambda d: torch.rand(8, d, dtype=torch.float64),
                                  batch_size=8, force_positive=True, force_self_adjoint=True)
assert A.matrix.shape == (8, 2, 3, 3)                           # (batch, C, k_max, k_max), block 0 padded
B = alg.from_blocks([torch.eye(2, dtype=alg.dtype), 2 * torch.eye(3, dtype=alg.dtype)])   # batch 1, broadcasts
X = A.sqrt() @ B @ A.sqrt()                                     # lazy
tr = X.Tr_blunt().real                                          # (8,)
assert torch.allclose(tr, states.trace_of_product(A, B).real)   # Tr(A^1/2 B A^1/2) = Tr(A B)
spectra = A.eigenvalues()                                       # list: (8, 2) and (8, 3)
assert [s.shape for s in spectra] == [(8, 2), (8, 3)]
assert torch.allclose(A.operator_norm(), A.lambda_max)          # a method and a property
t = torch.linspace(0.5, 2.0, 8, dtype=torch.float64)[:, None]   # one parameter per sample: shape (batch, 1)
At = A.apply_function(lambda w: w ** t)
```

### States, channels and dynamics

```python
from torch_vn_algebra import channels, dynamics

alg = TypeIAlgebra([3, 3], [3, 3], precision='double')
rho = states.random_density_matrix(alg, batch_size=16)
H = alg.operator_from_eigenvalues(lambda d: torch.randn(16, d, dtype=torch.float64),
                                  batch_size=16, force_self_adjoint=True)
Phi = channels.depolarizing_channel(alg, 0.3).compose(channels.random_channel(alg, kraus_rank=2))
assert Phi.is_trace_preserving()
D = states.relative_entropy(Phi(rho), Phi(states.gibbs_state(H, 1.0)))   # (16,), data processing
N = alg.from_blocks([torch.diag(torch.arange(3.0, dtype=torch.float64))] * 2)
rhos = dynamics.lindblad_evolve(rho, H, jumps=[N], times=[0.0, 0.5, 1.0])  # list of 3 states
L1 = dynamics.lindblad_channel(alg, H, jumps=[N], t=1.0)                   # exact exp(L), a Channel
assert (L1(rho).matrix - rhos[-1].matrix).abs().max() < 1e-6
assert torch.allclose(rhos[-1].sector_probabilities(), rho.sector_probabilities())  # sectors are conserved
```

### Spin chain: dense sector and Lanczos

```python
from torch_vn_algebra import SpinChain, krylov

chain = SpinChain(12, 'periodic')                     # double precision by default
H6 = chain.xxz(J=1.0, Delta=1.0, sector=6)            # dense block of the sector N = 6 (dimension 924)
E_dense = H6.eigenvalues()[0][:, 0]
E0, psi, residual = krylov.ground_state(chain.xxz_sparse(J=1.0, Delta=1.0, sector=6))
assert torch.allclose(E0, E_dense, atol=1e-8)
```

### Symmetry, commutant and conditional expectation

```python
from torch_vn_algebra import decompose as dc, inclusions as inc

G = dc.permutation_representation(3, 2)               # S_3 permuting three qubits: (6, 8, 8)
D = dc.from_group(G)
assert list(D.k_factors) == [1, 2] and list(D.multiplicities) == [4, 2]
N = TypeIAlgebra([2, 1], [2, 1], precision='double')
M = TypeIAlgebra([4, 3], [4, 3], precision='double')
I = inc.Inclusion(N, M, [[1, 2], [1, 1]])             # inclusion matrix: multiplicities of N's blocks in M's
E = I.conditional_expectation('markov')
y = M.operator(torch.randn(5, M.C, M.k_max, M.k_max, dtype=M.dtype))
assert E(y).algebra is N
index = I.index()                                     # ||Lambda||^2
```

### Packed storage, matrix-free sectors and trajectories

```python
from torch_vn_algebra import krylov

chain = SpinChain(10, 'periodic')                     # full algebra packed by default (layout='auto'):
H = chain.xxz(J=1.0, Delta=0.5)                       # sizes 1, 10, 45, ..., 252, no padding stored
assert [p.shape[-1] for p in H.parts][:3] == [1, 10, 45] and H.block(5).shape == (1, 252, 252)
E = torch.cat([w[0] for w in H.eigenvalues()]).min()  # per-sector spectra, no padded tensor formed

A = H.block(5)[0]                                     # a matrix-free operator from any function v -> H v
op = krylov.MatrixFreeOperator(lambda V: V @ A.T, 252, dtype=A.dtype)
E5, _ = krylov.lowest_eigenvalues(op, levels=2)
assert torch.allclose(E5[0], torch.linalg.eigvalsh(A)[:2], atol=1e-8)

small = SpinChain(4, 'periodic')                      # spin flips down with rate 0.2: jumps between sectors
jumps = [small.sector_jump(i, 'lower') for i in range(4)]
tr = dynamics.trajectories(small.basis_state('1101'), small.xxz(1.0, 0.5), jumps, [0.0, 1.0],
                           rates=[0.2] * 4, n_traj=2000)
mean, err = tr.mean(small.number())                   # <N>(t) with standard errors
exact = dynamics.lindblad_evolve(small.basis_state('1101'), small.xxz(1.0, 0.5), jumps, [0.0, 1.0],
                                 rates=[0.2] * 4)[-1].expectation(small.number()).real
assert abs(mean[-1] - exact[0]) < 5 * err[-1] + 0.02
```

### Measurement and spectral measure

```python
from torch_vn_algebra import POVM, spectral_measure

chain = SpinChain(4)
rho = states.random_density_matrix(chain.algebra, batch_size=3)
counts = POVM.basis(chain.algebra).sample(rho, shots=1000)       # computational basis, (3, 16)
P = spectral_measure(chain.heisenberg())                         # PVM: eigenvalues and spectral projections
assert torch.allclose(P.expectation(rho), rho.expectation(chain.heisenberg()).real)
```

### Learning a channel (torch.nn)

```python
from torch_vn_algebra import learn

alg = TypeIAlgebra([2, 2], [2, 2], precision='double')
target = channels.random_channel(alg, kraus_rank=2)
X = states.random_density_matrix(alg, batch_size=32)
net = learn.ChannelLayer(alg, kraus_rank=2)                      # every parameter value is a channel
opt = torch.optim.Adam(net.parameters(), lr=0.05)
for _ in range(200):
    opt.zero_grad()
    loss = learn.trace_distance(net(X), target(X)).mean()
    loss.backward()
    opt.step()
assert loss.item() < 0.05
```

### Continuous centre and anyon chain

```python
import math
from torch_vn_algebra import DirectIntegral, AnyonChain

Z = DirectIntegral.torus(64, dims=2)                             # Brillouin zone, 2 bands

def ssh(k):                                                      # k: nodes (64, 1)
    h = torch.zeros(k.shape[0], 2, 2, dtype=torch.complex128)
    z = 1 + 0.5 * torch.exp(1j * k[:, 0])
    h[:, 0, 1], h[:, 1, 0] = z.conj(), z
    return h

Hk = Z.field(ssh, is_self_adjoint=True)
e0 = Z.trace(Hk.apply_function(lambda w: w.clamp(max=0))).real  # filled lower band, per unit cell
golden = AnyonChain(3, 12)                                       # SU(2)_3: Fibonacci anyons
E = golden.low_energies(levels=2)                                # one tensor per total charge
assert abs(AnyonChain.central_charge(3) - 0.7) < 1e-12
```

## 6. Habits that avoid wrong results

- **Pick the precision.** Use double whenever the quantity is small compared with the operators: near-equality in
  inequalities, small gaps, entropies of nearly pure states, long integrations. Single precision is for Monte Carlo
  statistics.
- **Read the sector structure before indexing.** `alg.k_factors[c]` is the size of block `c`, and
  `op.matrix[:, c, :k, :k]` is the block itself.
- **Check invariants instead of trusting a formula.**
  - Use `Channel.is_trace_preserving()`, `rho.Tr_blunt()`, `rho.sector_probabilities()`, and
    `decompose.Decomposition.verify()` or `certificate()`.
  - The tests in `tests/` show the expected accuracy of each module.
- **Batch the samples.** Do not loop over samples in Python: one batch of 10^4 operators is one call.
- **Read the docstrings.** For theory, the lecture notes give the definitions behind every function: <https://andre-a-no.github.io/von_neumann_type_i/>.
- **Read the tutorial**, which runs every function in context: `man/tutorial/` in the repository.
